#Assimilação RPG — Gerador de Conflitos

Ferramenta web para criação de cards de conflito estilizados para campanhas de Assimilação RPG.
O projeto permite montar cenas completas de conflito de forma rápida, visual e altamente customizável, com exportação em imagem pronta para uso em sessões, PDFs ou materiais digitais.

Recursos
Sistema de criação modular de conflitos
Objetivos principais e secundários
Ativações e condicionantes personalizados
Sistema visual de símbolos e custos
Renderização automática de cards estilizados
Exportação em PNG com alta qualidade
Interface inspirada em tinta, papel e aquarela
Suporte a símbolos inline dentro dos textos
Organização visual para mesas de RPG narrativo e tático
Tecnologias
HTML5
CSS3
JavaScript Vanilla
html2canvas
Ideal para
Mestres de RPG

Materiais visuais para campanhas
Sistemas autorais de RPG
